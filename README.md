# C++ Data Structures Practicals

---

# Repository Overview

This repository contains C++ practical assignments demonstrating fundamental Data Structures concepts including Stack, Queue, and Linked List operations.

The programs are menu-driven and allow users to perform different operations interactively.

---

# Practical 1 – Stack Implementation

## Overview

A menu-driven Library Stack Management System that demonstrates the implementation of a Stack using an array.

## Features

* Return Book (Push)
* Arrange Book (Pop)
* View Top Book (Peek)
* Display Books in Stack
* Stack Overflow Handling
* Stack Underflow Handling

## Concepts Used

* Stack Data Structure
* Arrays
* Classes & Objects
* Constructors
* LIFO (Last In, First Out)
* Push Operation
* Pop Operation
* Peek Operation
* Overflow & Underflow

# Practical 2 – Linear Queue Implementation

## Overview

* Delete Element (Dequeue)
* Display Queue
* View Front Element (Peek)
* Queue Overflow Handling
* Queue Underflow Handling

## Concepts Used

* Queue Data Structure
* Arrays
* Classes & Objects
* Constructors
* FIFO (First In, First Out)
* Enqueue Operation
* Dequeue Operation
* Peek Operation
* Overflow & Underflow

# Practical 3 – Singly Linked List

## Overview

A menu-driven Singly Linked List program that demonstrates dynamic memory allocation and different linked list operations.

## Features

* Create Linked List
* Insert Node at Beginning
* Insert Node at End
* Delete Node
* Display Linked List
* Handle Empty List

## Concepts Used

* Linked List
* Nodes
* Pointers
* Dynamic Memory Allocation
* Classes & Objects
* Singly Linked List
* Insertion
* Deletion
* Traversal
